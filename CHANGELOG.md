# Changelog

### Added
- CRM clientes, facturas PDF nativas, Bizum/Crypto payments
- SSO OAuth2 (Google, GitHub, Microsoft)
- RBAC + ABAC, API Keys, webhooks bidireccionales

- Prometheus `/metrics`, Grafana dashboard
- WebSocket server + long-polling API
- Backups incrementales, health-check script
- 9 fases de módulos ERP completos (~260 archivos)

### Stack
- PHP 8.3+, MySQL 8, Bootstrap 5.3, MVC propio
- JWT, SSE, GraphQL, Redis, Docker, CI GitHub Actions
